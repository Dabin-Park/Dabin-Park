# Talk materials

Slides and posters for the talks listed under
[Conference presentations](../README.md#conference-presentations) in the CV.
One folder per paper, and inside it one folder per event, named `YYYY-MM-<venue>`.

The title a talk carried often differs from the one the paper was finally published under,
so each entry records the wording actually used on the deck or poster.
